# Stash app icon

Master artwork: `icon.png` (1024 × 1024, opaque RGB), drawn by `make_icon.py` (Pillow):
three stacked near-black slabs with a chevron dropping into the top one, on Stash mint (`#3DD6A3`).
It follows Midoku's icon style: one flat saturated background and a bold solid glyph.
The same artwork is used for the app icon and the source listing.

Regenerate with `python3 make_icon.py` and copy `icon.png` to
`iTorrent/Core/Assets/Assets.xcassets/AppIcons/AppIcon.appiconset/Stash.png`.

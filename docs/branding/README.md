Create a restrained, minimalist flat icon: one simple warm muted orange downward arrow ending just above a shallow horizontal tray, centered on a solid dark charcoal square background. Clean geometric shapes, consistent stroke weight, excellent legibility at 48 pixels, generous negative space. Completely flat two-color vector-like appearance. Full-bleed 1024x1024 square, background extends to all edges. No gradient, no glow, no shine, no shadows, no texture, no ribbon, no 3D, no borders, no baked-in rounded outer corners, no lettering or text, no watermark.

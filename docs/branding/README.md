# Drift app icon

Master artwork: `icon.png` (1024 × 1024, opaque RGB), drawn by `make_icon.py` (Pillow):
a mint (`#3DD6A3`) globe ring with a darker meridian and equator, and a white download arrow
dropping through it, on near-black (`#0B0B0F`), matching the app's dark UI.
The same artwork is used for the app icon and the source listing.

Regenerate with `python3 make_icon.py` and copy `icon.png` to
`iTorrent/Core/Assets/Assets.xcassets/AppIcons/AppIcon.appiconset/Drift.png`.
